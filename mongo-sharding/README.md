# Шардирование MongoDB

Этот этап добавляет `mongos` и два шарда. Каждый шард пока состоит из одного узла, поэтому в MongoDB он настроен как одноузловой replica set. Config Server состоит из трёх узлов.

## Запуск и инициализация

```sh
docker compose up -d
./scripts/mongo-init.sh
```

Скрипт создаёт config replica set, регистрирует шарды, включает шардирование `somedb.helloDoc` по полю `age`, переносит диапазон от 500 на `shard2` и добавляет 1000 документов. Повторный запуск не дублирует данные.

Проверьте `http://localhost:8080/` и `http://localhost:8080/docs`. API показывает topology `Sharded`, общее количество документов, распределение документов и число узлов в каждом шарде.
