# Шардирование с репликацией

На этом этапе каждый из двух шардов состоит из трёх MongoDB-узлов. Config Server также использует три узла.

## Запуск и инициализация

```sh
docker compose up -d
./scripts/mongo-init.sh
```

Скрипт настраивает `shard1RS` и `shard2RS`, регистрирует оба replica set в `mongos`, включает шардирование `somedb.helloDoc` по `age`, распределяет диапазоны между шардами и создаёт 1000 тестовых документов.

Проверьте `http://localhost:8080/` и `http://localhost:8080/docs`. В JSON должны быть тип topology `Sharded`, два шарда, число узлов в каждом шарде, общее количество документов и их количество на каждом шарде. Для статуса реплик подключитесь к узлу replica set через `mongosh` и выполните `rs.status()`.
